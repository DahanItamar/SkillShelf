# Citation Index

Every instrument named in any module's `instruments` frontmatter, with its official text and
the date that text was last accessed.

The `Instrument` cell matches the module frontmatter `name` field **byte for byte** — that
equality is what `AC-056` checks, and it is why the names read as they do rather than as
tidier titles. Five instruments appear in two modules each; they are listed once.

**Access date is not currency.** A date here means someone opened the official text on that
day. It does not mean the instrument is unchanged since, and it does not mean the module's
reading of it is right. The instruments marked **volatile** below moved within the last
eighteen months and are the ones to re-check first.

certified.

## Known citation defect, kept deliberately

**NIST SP 800-147B** is *BIOS Protection Guidelines for Servers* — platform firmware, not
application binary integrity. It is cited by the ACSM source material and retained in module 7's
`instruments` so the provenance stays traceable, but module 7's obligations cite **NIST SP
800-218 (SSDF) PS.2**, which is the applicable guidance. Do not propagate 800-147B into new
material.

## Maintaining this file

`scripts/verify.sh` fails when a module names an instrument this file does not carry
(`AC-056`). It cannot check the reverse, and it cannot check that a URL still resolves or that
the text behind it is unchanged — those need a human. When a module gains an instrument, add
the row in the same commit.
